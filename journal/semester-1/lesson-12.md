Without reprucing the error any thing done to fix the error is a guess at best or making things worse at the worst
1. **Why should you change only one variable at a time?**  
So you can track where the actual fix occurs and ideally note it the code and any version control docs
1. **What makes a good debugging hypothesis?**  
Something that can be measured and have evidence of the cause and the solution

I use the rubber duck process all the time, sometimes just saying things out load will trigger an idea
